# Architecture and Product Decision Records

Decision records are numbered once, in chronological order. Accepted decisions remain immutable historical records; superseding decisions receive a new number rather than reusing an existing one.

| ADR | Decision | Status |
|---|---|---|
| [ADR-0001](ADR-0001-polyglot-architecture.md) | Polyglot architecture by responsibility | Accepted |
| [ADR-0002](ADR-0002-v1-local-first-data.md) | Local-first V1 data and persistence | Accepted |
| [ADR-0003](ADR-0003-confirmed-zero-and-null-financial-inputs.md) | Confirmed zero, unknown financial inputs, and outcome explanations | Accepted |
| [ADR-0004](ADR-0004-derive-cash-upfront.md) | Derive cash-purchase upfront amount from price and fees | Accepted |
| [ADR-0005](ADR-0005-protected-savings-opt-in.md) | Explicit protected-savings opt-in and disclosure | Accepted |

When adding a decision, choose the next unused number and update this index. Do not create multiple records with the same ADR number.
