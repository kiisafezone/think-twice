# THINK TWICE.

**Think twice today. Thank yourself tomorrow.**

THINK TWICE. is a **Personal Financial Decision Companion** that helps people evaluate a purchase before making a financial commitment.

This repository contains the brand and product documentation, maintained as four separate references.

## Core product architecture

The product keeps three connected systems distinct:

- **Purchase Decision Assessment** — evaluates motivation, needs versus wants, urgency, social pressure, alternatives, expected regret, and long-term value.
- **Financial Reality Check** — evaluates available funds, income, expenses, savings, debt, PayLater, installments, repayment costs, due dates, and cash flow.
- **Decision Intelligence** — combines both assessments transparently and explains the recommendation.

**Purchase Decision Assessment remains a core product feature.** Financial calculations complement the assessment; they do not replace it.
